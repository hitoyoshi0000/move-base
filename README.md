# MOVE BASE FITNESS GYM

Static website for MOVE BASE (HTML / CSS / vanilla JS, no build step).

- `index.html` — page markup
- `css/style.css` — styles (breakpoints: desktop ≥ 960px, tablet 640–959px, mobile < 640px)
- `js/main.js` — mobile menu toggle
- `assets/` — images and icons

Deploy: any static host. On Vercel, use framework preset "Other" with no build command and the repository root as the output.
